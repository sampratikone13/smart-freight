What Does This Mean? — Academic Interpretation Guide

Key observations from the 7-model regression benchmark, designed for viva and lab-report readiness.

KEY FINDING Tree Models Outperform Linear Models

Decision Tree and Random Forest regressors achieve lower RMSE than all linear variants. This is because shipping duration depends on nonlinear interactions between carrier type, geographic region, and order characteristics — patterns that tree-based splits capture but linear coefficients cannot. Tree models learn conditional rules like IF Shipping Mode = "Same Day" AND Region = "Western Europe" → predict 0.8 days.

BASELINE Scheduled Days Alone Is Insufficient

Simple Linear Regression using only Days for shipment (scheduled) achieves R² ≈ 0.286, meaning scheduled shipping days explain only ~29% of actual delivery variance. Adding carrier mode, geography, order timing, and product attributes (Multiple Linear Regression) significantly improves predictive power. This confirms that actual shipping duration is influenced by many operational factors beyond just the promised schedule.

REGULARIZATION L1 Sparsity vs. L2 Shrinkage

Lasso (L1) drives many one-hot-encoded region/country coefficients to exactly zero, performing automatic feature selection. Ridge (L2) keeps all features but shrinks correlated coefficients evenly, better handling multicollinearity among geographically overlapping dummies. Elastic Net combines both penalties. Cross-validation selects optimal α (penalty strength) and ρ (L1/L2 ratio), balancing sparsity and stability.

PRACTICAL Business Implications

The best-performing model achieves RMSE ≈ 1.23 days, meaning predictions are typically within ±1.23 days of actual delivery. For logistics planning, this enables: (1) proactive customer notification when delays are predicted, (2) dynamic buffer-time allocation, and (3) carrier performance auditing. The coefficient chart reveals which features (shipping mode, market region) most influence delivery time.

📐 Metric Definitions — Quick Reference
MAE — Mean Absolute Error. Average absolute prediction deviation in days. Robust to outliers.
MSE — Mean Squared Error. Average of squared residuals. Penalizes large errors quadratically.
RMSE — Root Mean Squared Error. Square root of MSE; same unit as target (days). Primary ranking metric.
R² Score — Coefficient of Determination. Proportion of variance explained (1.0 = perfect; 0.0 = predicts the mean).

Technical Details & Pipeline Specifications

Audited machine learning parameters, mathematical formulas, and data preparation pipeline details.

📖 Complete Feature Matrix & Regularization Formulas (Click to expand)

Target Variable: Days for shipping (real) (Continuous float, min=0.0, max=6.0).

Approved Pre-Shipment Features:

  • Numerical (12): Days for shipment (scheduled), Order Item Quantity, Sales, Order Item Discount, Product Price, Latitude, Longitude, order_month, order_day, order_weekday, order_hour, is_weekend.
  • Categorical (9): Shipping Mode, Type, Customer Segment, Market, Order Region, Order Country, Order State, Category Name, Department Name.

Mathematical Loss Objectives:

  • Ordinary Least Squares (OLS): \(\min_w ||y - Xw||_2^2\)
  • Lasso (L1): \(\min_w \frac{1}{2n} ||y - Xw||_2^2 + \alpha ||w||_1\) (Enforces sparse feature selection)
  • Ridge (L2): \(\min_w ||y - Xw||_2^2 + \alpha ||w||_2^2\) (Mitigates multicollinearity among carrier regions)
  • Elastic Net: \(\min_w \frac{1}{2n} ||y - Xw||_2^2 + \alpha \rho ||w||_1 + \frac{\alpha(1-\rho)}{2} ||w||_2^2\)

Cross-Validation Tuning:

  • LassoCV: Tests α ∈ {0.0001, 0.001, 0.01, 0.05, 0.1, 0.5, 1.0} with 3-fold CV.
  • RidgeCV: Tests α ∈ {0.01, 0.1, 1.0, 10.0, 50.0, 100.0, 500.0} with 3-fold CV.
  • ElasticNetCV: Tests α × ρ grid with ρ ∈ {0.1, 0.2, 0.5, 0.7, 0.9} and 3-fold CV.

Preprocessing Pipeline:

  • Numeric: SimpleImputer(strategy='median') → StandardScaler()
  • Categorical: SimpleImputer(strategy='most_frequent') → OneHotEncoder(min_frequency=20, handle_unknown='ignore')
  • Split: 80% Train / 20% Test, random_state=42
